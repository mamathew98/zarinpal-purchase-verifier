# Zarinpal Purchase Verifier

## HOWTO
1. Add a `tokens.json` file containing the access tokens for each application per store like below (or use admin app):
  ```
{
  'zarin_tokens' {
    "com.test.app1": "...."
    "com.test.app2": "...."
  }
}
```
3. Use admin app to select/modify desired application in the output and make a build
4. Copy the build folder anywhere and use it
